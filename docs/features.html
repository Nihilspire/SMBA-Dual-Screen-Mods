FEATUREDUALLINK

Dual is everything in one app: its own emulator, the game on one screen and the Link screen on the other.

Link is only the Link screen, for playing in RetroArch. "Use RetroArch" means Link leaves that to RetroArch's own settings.

Alpha: Link has only run against RetroArch on a PC so far, not yet on an Android device.

Fan-made and not affiliated with Nintendo. No game data is included: both apps need your own Super Mario Advance (USA, Europe) ROM.
